# Project Overview

## What
mathsets-kt — Kotlin Multiplatform library implementing ZFC axiomatic set theory and the complete number tower (ℕ → ℤ → ℚ → ℝ → ℂ), combining mathematical rigor with software engineering.

## Why
Resolve the "Bootstrap Circular" between Set Theory and Number Theory. Serves as both an efficient computational tool and a rigorous didactic laboratory, proving isomorphism between optimized kernel and axiomatic construction.

## Scope
- **In:** ZFC axioms, first-order logic, MathSet, relations, functions, Von Neumann construction, number tower, ordinals (CNF), cardinals, finite topology, Borel hierarchy, combinatorics (Ramsey), forcing, algebra, polynomials, Galois theory, category theory, type theory, computability, model theory, linear algebra, number theory, graph theory, analysis, SAT solver, proof objects, symbolic computation, ODEs
- **Out:** Complex GUIs, exotic hardware support
